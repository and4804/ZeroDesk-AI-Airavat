2. System Architecture Overview
AgentFinance AI is a 10-tier agentic pipeline that processes a live video call end-to-end — from session initiation
through fraud assessment, credit decisioning, and loan offer delivery. Each module communicates via a well-defined
REST or WebSocket contract and emits structured audit events to an immutable append-only log in Supabase. Redis
handles all ephemeral session state, pub/sub event bus, and rate-limiting.

Data flow summary: Every module reads from and writes to Supabase. Real-time coordination (session heartbeat,
stage progression, fallback triggers) travels through Redis Streams. The orchestrator (M09) is the only module allowed
to advance the pipeline state machine; all other modules emit events and wait.

3. Module Specifications (M01 – M10)
Each module below is independently deliverable. Modules communicate only through the defined API contracts —
no module imports another's internal code. Colour coding: Blue = primary API, Green = event emitted to Redis,
Amber = Supabase write.
M0
1
Session & Video Call Infrastructure
Tier: Tier 1 | Owner: Dev A | Time: 2–3 hrs
Responsibility: Issue tamper-proof session tokens, establish browser-native WebRTC video sessions, capture device
fingerprint and geolocation on session initiation, maintain heartbeat.
Key deliverables:
• Token generation endpoint: POST /api/sessions/create — returns signed JWT with session_id
• Token validation middleware — attaches session context to every downstream request
• WebRTC signalling server (Socket.io) for ICE/SDP exchange
• Device fingerprint capture on page load (User-Agent, screen resolution, timezone, canvas hash)
• Geolocation capture via browser Geolocation API (lat/lng stored in session metadata)
• Session heartbeat — Redis key with 5-min TTL, auto-renewed every 30s
• Session state stored in Redis hash session:{id}

Consent Capture & Auditable Consent Trail
Tier: Tier 3 | Owner: Dev A/B | Time: 1–2 hrs
Responsibility: Monitor the live transcript for verbal consent phrases, timestamp and hash the exact consent
segment, build a tamper-evident consent record exportable as a signed JSON artifact for regulatory compliance.
Key deliverables:
• Keyword/phrase matcher running on each new transcript segment (regex + fuzzy match)
• Consent phrases: "I agree", "yes I consent", "I accept", "haan mujhe manzoor hai" (Hindi)
• SHA-256 hash of the verbatim transcript segment stored alongside consent record
• Consent record written to Supabase consent_records table (immutable — no UPDATE allowed)
• Signed artifact: JSON with session_id, timestamp, phrase, hash, segment_text
• Opt-out detection: "I do not consent" → session flagged, pipeline halted gracefully

Computer Vision — Liveness Detection & Age Estimation
Tier: Tier 4 | Owner: Dev C | Time: 3–4 hrs
Responsibility: Periodically sample JPEG frames from the WebRTC stream, run liveness detection (anti-spoofing)
using MediaPipe Face Mesh, estimate the applicant's age using DeepFace, flag age inconsistency vs. declared age.
Key deliverables:
• Frontend: capture frame every 3s via canvas.toDataURL(), POST to vision endpoint
• MediaPipe Face Mesh: detect 468 landmarks — blink detection via EAR (Eye Aspect Ratio) proves liveness
• Anti-spoofing heuristics: check for texture variance (photo has low variance), blink rate, head pose jitter
• DeepFace age estimation: AgeGenderModel (lightweight, no GPU needed)
• Age delta check: |estimated_age - declared_age| > threshold (default: 8 years) → flag session
• Liveness score (0–1) stored per frame, rolling average over last 5 frames
• Session flagged if liveness_avg < 0.6 for > 15 consecutive seconds
• All frame analysis results logged to Supabase vision_events

LLM Intelligence Layer — Intent & Risk Persona
Tier: Tier 5 | Owner: Dev D | Time: 3–4 hrs
Responsibility: Process the full session transcript through a structured LLM reasoning chain to assign a loan intent
category, a risk persona label, and produce a chain-of-thought (CoT) reasoning trace. No black-box outputs — every
classification must be explainable.
Key deliverables:
• Intent classification: home_improvement, medical, education, debt_consolidation, business, personal, wedding,
travel
• Risk persona: first_time_borrower, conservative_borrower, distressed_borrower, high_income_stable,
self_employed_variable
• Structured CoT trace: {"reasoning_steps": [...], "evidence": [...], "conclusion": "..."}
• Tone analysis: detect financial distress signals (desperation language, urgency markers)
• Contradiction detection: cross-check stated income vs. loan amount vs. purpose plausibility
• Multi-turn context: include previous clarification Q&A; in the LLM context
• All outputs immutably logged to llm_assessments table with full prompt

8
Loan Offer Generation & In-Call Negotiation Agent
Tier: Tier 8 | Owner: Dev D/E | Time: 2–3 hrs
Responsibility: Generate a personalised loan offer based on bureau + fraud + LLM outputs. An LLM negotiation
sub-agent handles objections in real time, simulates EMI impact, and logs every accepted/rejected offer term.
Offer formula:
• Eligible amount: min(requested_amount, 0.3 × annual_income, bureau_limit)
• Interest rate: base_rate (11%) + risk_premium (0–4% based on credit_score band) + fraud_premium (0–2%)
• Tenure options: 12, 24, 36, 48, 60 months — presented with EMI for each
• EMI formula: P × r × (1+r)^n / ((1+r)^n - 1) where r = monthly rate
• Negotiation rounds: up to 3 counter-offers allowed before final decision
